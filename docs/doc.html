Guardar y cargar
  • 💾 Guardar sesión (.zip) — canvas + configuración completa
  • 📂 Cargar sesión (.zip) — restaura un canvas guardado
  • 🗺 Exportar (.json) — estructura y conexiones
Los datos no se persisten entre sesiones. Al restaurar, recarga el dataset en Datos.
Notas técnicas
  • Servidor en localhost:5053, sin puertos externos
  • Modelos en memoria — se borran al reiniciar
  • Gráficas con matplotlib → PNG en base64
  • Cada nodo Datos tiene slot _NODE_DATA[id]
  • SPA sin frameworks — estado en memoria JS

More information
Saving and loading
  • 💾 Save session (.zip) — canvas + full configuration
  • 📂 Load session (.zip) — restores a saved canvas
  • 🗺 Export (.json) — block structure and connections
Data is not persisted between sessions. When restoring, reload the dataset in the Data block.
Technical notes
  • Server on localhost:5053, no external ports
  • Models in memory — cleared on restart
  • Plots via matplotlib → base64 PNG
  • Each Data node has slot _NODE_DATA[id]
  • Framework-free SPA — canvas state in JS memory
