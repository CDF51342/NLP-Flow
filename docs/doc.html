Pipeline RAG
¿Qué es RAG?

RAG (Retrieval-Augmented Generation) combina búsqueda semántica y generación de texto. El LLM recibe los fragmentos más relevantes de tu corpus como contexto en el prompt — la diferencia entre "sin RAG" y "con RAG" es literalmente más texto en el input.

Flujo completo

📂 Datos
→
✂️ Chunking

🧬 Embeddings
→
🔎 Retriever
→
🤖 LLM (RAG)
→
💾 Guardar
Configuración necesaria

El bloque LLM requiere un token de Hugging Face. Crea un fichero .env en la raíz del proyecto:

HF_TOKEN=hf_tutoken
HF_LLM_MODEL=Qwen/Qwen2.5-7B-Instruct

Los embeddings funcionan sin token (modelo all-MiniLM-L6-v2).

⚠️ Sin HF_TOKEN el bloque LLM no generará respuestas. Los demás bloques RAG funcionan sin él.
Qué ve el estudiante
  • Sin RAG: el LLM responde solo con su conocimiento preentrenado
  • Con RAG: el LLM recibe los N fragmentos más similares del corpus como contexto
  • Las dos respuestas aparecen en paralelo para comparar
  • El bloque Guardar exporta un informe HTML con toda la sesión

RAG Pipeline
What is RAG?

RAG (Retrieval-Augmented Generation) combines semantic search and text generation. The LLM receives the most relevant fragments from your corpus as context in the prompt — the difference between "without RAG" and "with RAG" is literally more text in the input.

Full flow

📂 Data

🔎 Retriever
→
🤖 LLM (RAG)
→
💾 Save
Required configuration

The LLM block requires a Hugging Face token. Create a .env file in the project root:

HF_TOKEN=hf_yourtoken
HF_LLM_MODEL=Qwen/Qwen2.5-7B-Instruct

Embeddings work without a token (model all-MiniLM-L6-v2).

⚠️ Without HF_TOKEN the LLM block will not generate responses. All other RAG blocks work without it.
What the student sees
  • Without RAG: the LLM answers using only its pre-trained knowledge
  • With RAG: the LLM receives the N most similar fragments from the corpus as context
  • Both responses are shown side by side for comparison
  • The Save block exports an HTML report with the full session

Saving and loading
  • 💾 Save session (.zip) — canvas + full configuration
  • 📂 Load session (.zip) — restores a saved canvas
  • 🗺 Export (.json) — block structure and connections

Data is not persisted between sessions. When restoring, reload the dataset in the Data block.
Technical notes
  • Server on localhost:5053, no external ports
  • Embeddings: all-MiniLM-L6-v2 via HF Inference API
  • LLM: Qwen/Qwen2.5-7B-Instruct via HF router
  • RAG state in _RAG[chunk_node_id]
  • Plots via matplotlib → base64 PNG
  • Framework-free SPA — canvas state in JS memory
