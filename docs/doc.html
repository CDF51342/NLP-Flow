NLP Flow v4

Entorno visual de machine learning basado en pipelines. Conecta bloques en un canvas, configura cada uno con doble clic y ejecuta el flujo completo con un botón. Sin código.

Sin código Python 3.10+ Flask scikit-learn RAG · LLM localhost:5053
Requisitos y arranque

Instala dependencias:

pip install -r requirements.txt

Modo escritorio — ventana nativa:

python main.py

Solo navegador:

python server.py
# http://localhost:5053

Guardar y cargar
  • 💾 Guardar sesión (.zip) — canvas + configuración del servidor
  • 📂 Cargar sesión (.zip) — restaura un canvas guardado
  • 🗺 Exportar canvas (.json) — abre diálogo nativo del sistema para elegir ruta
  • 📥 Importar canvas (.json) — restaura bloques, conexiones y estado visual
  • 📄 Informe RAG (.html) — consulta, fragmentos y respuestas
Los datos no se persisten entre sesiones. Al restaurar, recarga el dataset en el bloque Datos.
Notas técnicas
  • Servidor en localhost:5053, sin puertos externos
  • Embeddings: all-MiniLM-L6-v2 vía HF Inference API
  • LLM: Qwen/Qwen2.5-7B-Instruct vía HF router
  • Stemming con SnowballStemmer — detecta ES/EN automáticamente
  • Lemmatización con spaCy (en_core_web_sm + es_core_news_sm)
  • Gráficas con matplotlib → PNG en base64
  • SPA sin frameworks — estado en memoria JS + node.data

More information
Saving and loading
  • 💾 Save session (.zip) — canvas + full server configuration
  • 📂 Load session (.zip) — restores a saved canvas
  • 🗺 Export canvas (.json) — opens the native OS file dialog to choose the path
  • 📥 Import canvas (.json) — restores blocks, connections and visual state
  • 📄 RAG Report (.html) — query, fragments and responses
Data is not persisted between sessions. When restoring, reload the dataset in the Data block.
Technical notes
  • Server on localhost:5053, no external ports
  • Embeddings: all-MiniLM-L6-v2 via HF Inference API
  • LLM: Qwen/Qwen2.5-7B-Instruct via HF router
  • Stemming via SnowballStemmer — auto-detects ES/EN language
  • Lemmatisation via spaCy (en_core_web_sm + es_core_news_sm)
  • Plots via matplotlib → base64 PNG
  • Framework-free SPA — canvas state in JS memory + node.data
