Pipeline Topic Model
¿Qué es Topic Modeling?

El topic modeling es aprendizaje no supervisado: el modelo descubre automáticamente los temas latentes de un corpus de texto sin necesitar etiquetas. A diferencia de clasificación, no hay variable objetivo — el algoritmo agrupa palabras y documentos por co-ocurrencia estadística.

📂 Datos
🔧 Preprocesado
🗂 Topic Model
💾 Guardar
Algoritmos disponibles
AlgoritmoBase matemáticaMejor para
LDAProbabilístico (Dirichlet)Texto general, muchos documentos
NMFFactorización matricial no negativaTópicos más limpios, corpus pequeños
LSAÁlgebra lineal (SVD)Semántica latente, sinónimos
💡 El bloque vectoriza internamente con CountVectorizer (LDA) o TfidfVectorizer (NMF/LSA). No hace falta un bloque BoW previo.
Lo que ve el estudiante
  • Tópicos con palabras clave — tabla con las N palabras más relevantes por tópico
  • Word clouds — una nube de palabras por tópico, generada automáticamente
  • Topic diversity — métrica 0–1 de cuán distintos son los tópicos entre sí (1 = máxima diversidad)
  • C_V — coherencia basada en similitud coseno de vectores NPMI indirectos; rango [0, 1], mayor es mejor
  • C_NPMI — NPMI pairwise promedio de las palabras clave; rango [−1, 1], valores positivos indican co-ocurrencia relevante
  • Distribución de documentos — qué porcentaje de cada documento pertenece a cada tópico
Parámetros clave
ParámetroDescripción
Nº tópicos (K)Cuántos temas extraer del corpus; probar K = 5, 8, 10, 15, 20 para encontrar el óptimo
Vocabulario máximoPalabras más frecuentes del corpus incluidas en la matriz (100–5 000); valores bajos como 500 pueden limitar la coherencia
Palabras por tópicoCuántas palabras clave mostrar por tópico
IteracionesPasadas de optimización (hasta 2 000); más = mayor coherencia para LDA; para convergencia se para automáticamente
AlgoritmoLDA, NMF o LSA — selector en el panel lateral
Etiquetado automáticoOpcional: etiqueta cada tópico con un nombre generado por el LLM, en el idioma del corpus
⚙️ Parámetros avanzados (sección desplegable en el panel)
min_df — frecuencia mínima de documento: elimina términos rarísimos (valores: 1–10).
max_df — fracción máxima de docs en que puede aparecer un término: elimina palabras demasiado comunes (0.1–1.0).
Stopwords — activa el filtrado automático de stopwords según el idioma detectado del corpus.
Alpha (solo LDA) — prior doc-tópico: valores bajos (0.01–0.1) concentran cada documento en pocos tópicos; recomendado para corpus con categorías bien definidas como BBC News.
Beta (solo LDA) — prior tópico-palabra: valores bajos (0.01–0.05) generan tópicos más especializados.

Pipeline RAG
¿Qué es RAG?

RAG (Retrieval-Augmented Generation) combina búsqueda semántica y generación de texto. El LLM recibe los fragmentos más relevantes de tu corpus como contexto en el prompt — la diferencia entre "sin RAG" y "con RAG" es literalmente más texto en el input.

Configuración necesaria

El bloque LLM usa la API de Hugging Face. Crea un fichero .env en la raíz del proyecto:

HF_TOKEN=hf_tutoken
HF_LLM_MODEL=meta-llama/Llama-3.1-8B-Instruct

Los embeddings funcionan sin token (modelo all-MiniLM-L6-v2).

⚠️ Sin HF_TOKEN el bloque LLM no generará respuestas. Los demás bloques RAG (Chunking, Embeddings, Retriever) funcionan sin él.
Qué ve el estudiante
  • Sin RAG: el LLM responde solo con su conocimiento preentrenado
  • Con RAG: el LLM recibe los N fragmentos más similares del corpus como contexto
  • Las dos respuestas aparecen en paralelo para comparar
  • El bloque Guardar exporta un informe HTML con toda la sesión

Pipeline Autoencoder
¿Qué es un Autoencoder?

Un autoencoder es una red neuronal no supervisada que aprende a comprimir una imagen a un vector de baja dimensión (espacio latente) y luego reconstruirla desde ese vector. No necesita etiquetas — el objetivo es que la imagen de salida sea lo más parecida posible a la de entrada. Es la introducción ideal al concepto de representación en deep learning.

Topic Model Pipeline
What is Topic Modeling?

Topic modeling is unsupervised learning: the model automatically discovers latent themes in a text corpus without needing labels. Unlike classification, there is no target variable — the algorithm groups words and documents by statistical co-occurrence.

Full flow

📂 Data
🔧 Preprocessing
🗂 Topic Model
💾 Save
Available algorithms
AlgorithmMathematical basisBest for
LDAProbabilistic (Dirichlet)General text, large corpora
NMFNon-negative matrix factorisationCleaner topics, smaller corpora
LSALinear algebra (SVD)Latent semantics, synonyms
💡 The block vectorises internally with CountVectorizer (LDA) or TfidfVectorizer (NMF/LSA). No separate BoW block is needed.
What the student sees
  • Topics with keywords — table with the N most relevant words per topic
  • Word clouds — one word cloud per topic, generated automatically
  • Topic diversity — 0–1 metric of how distinct the topics are from each other (1 = maximum diversity)
  • C_V — coherence based on cosine similarity of indirect NPMI vectors; range [0, 1], higher is better
  • C_NPMI — average pairwise NPMI of the top keywords; range [−1, 1], positive values indicate meaningful co-occurrence
  • Document distribution — what percentage of each document belongs to each topic
Key parameters
ParameterDescription
No. of topics (K)How many themes to extract from the corpus; try K = 5, 8, 10, 15, 20 to find the optimum
Max vocabularyMost frequent words included in the matrix (100–5,000); low values like 500 may limit coherence
Words per topicHow many keywords to show per topic
IterationsOptimisation passes (up to 2,000); more = higher coherence for LDA; stops automatically on convergence
AlgorithmLDA, NMF or LSA — selector in the side panel
Auto-labellingOptional: labels each topic with a name generated by the LLM, in the corpus language
⚙️ Advanced parameters (collapsible panel section)
min_df — minimum document frequency: drops extremely rare terms (values: 1–10).
max_df — maximum fraction of docs a term may appear in: removes overly common words (0.1–1.0).
Stopwords — enables automatic stopword filtering based on the detected corpus language.
Alpha (LDA only) — doc-topic prior: low values (0.01–0.1) concentrate each document on fewer topics; recommended for corpora with clear categories such as BBC News.
Beta (LDA only) — topic-word prior: low values (0.01–0.05) produce more specialised topics.

Required configuration

The LLM block uses the Hugging Face API. Create a .env file in the project root:

HF_TOKEN=hf_yourtoken
HF_LLM_MODEL=meta-llama/Llama-3.1-8B-Instruct

Autoencoder Pipeline
What is an Autoencoder?

An autoencoder is an unsupervised neural network that learns to compress an image into a low-dimensional vector (latent space) and then reconstruct it from that vector. No labels are needed — the goal is for the output image to be as close as possible to the input. It is the ideal introduction to the concept of representation learning in deep learning.
